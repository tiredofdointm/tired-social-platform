# Development instructions
Read docs/PLAN.md, docs/BACKLOG.md and docs/SESSION.md first.
This is an independent Google Cloud social/events/talent platform. No Laravel.
Keep the UI polished, responsive, accessible and customizable.
Do not misrepresent local demo actions as live payments, invitations or shared data.
Choose the highest-priority ready task. Complete and verify a bounded user journey.
Run npm run check, npm test and relevant browser checks before declaring changes verified.
Never commit secrets. Do not modify unrelated repositories or existing cloud services.
Update the session checkpoint with actual evidence, blockers and the next task.
