# Development instructions
Read docs/PLAN.md, project/progress.json, docs/BACKLOG.md and docs/SESSION.md first.
This is an independent Google Cloud social/events/talent platform. No Laravel.
Keep the UI polished, responsive, accessible and customizable.
Do not misrepresent local demo actions as live payments, invitations or shared data.
Use the designated next ready task; document any priority change.
One primary task in progress. Do not retry blocked approaches without satisfying their recorded retry conditions.
Run npm run check, npm test and relevant browser/database checks before declaring changes verified.
Update project/progress.json with status and reviewed evidence; update docs/SESSION.md with exact next action.
Run node scripts/progress.mjs after progress changes; the workflow enforces dependency and evidence metadata.
Never commit secrets. Do not modify unrelated repositories or existing cloud services.
